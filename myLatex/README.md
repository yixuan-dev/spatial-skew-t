# Graduation-Thesis

碩士畢業論文 Tex 存放區，含自製模板

## 說明

此論文 Latex 安裝過程參考 [2025 TexLive+VScode排版IEEE TGRS论文](https://blog.csdn.net/qq_53182191/article/details/150058750?spm=1001.2101.3001.6650.3&utm_medium=distribute.pc_relevant.none-task-blog-2~default~YuanLiJiHua~Position-3-150058750-blog-105369694.235%5Ev43%5Epc_blog_bottom_relevance_base7&depth_1-utm_source=distribute.pc_relevant.none-task-blog-2~default~YuanLiJiHua~Position-3-150058750-blog-105369694.235%5Ev43%5Epc_blog_bottom_relevance_base7&utm_relevant_index=6) 文章進行安裝，並在安裝過程中使用 [TeX Live ](https://tug.org/texlive/acquire-netinstall.html) 作為底層編譯器，與使用 VScode 作為使用時的程式碼編輯器。

為求在各作業系統間都能獲得一致的書寫體驗，本專案在檔案管理採以相對路徑的方式進行讀取，並盡量不使用絕對路徑，減少必須在各操作系統上調整路徑的麻煩。
