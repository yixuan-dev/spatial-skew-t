

1. 決定 $F$ 是完全固定的
2. 確認 $ (F^{'}F)^{-1/2} $ 在程式中如何實踐



**先決定統計立場**

- 最重要的一點是：你現在這個方法已經不再是「full Bayes for \(M\)」，而是 **Bayesian hierarchical model + profile / plug-in covariance update**。這本身沒有問題，但要先講清楚。否則實作完之後，會卡在「這個 MCMC 到底收斂到哪個 posterior」。
- 更直接地說，如果每次 iteration 都用 Theorem 2 把 \(\widehat M\) 和 \(\widehat{\sigma}_\xi^2\) 代回去，而不是對它們抽樣，這個演算法比較像 hybrid MCMC/ECM 或 empirical Bayes，而不是嚴格的 Gibbs/MH。
- 所以第一個要做的決策是：我們是否接受這個 inferential target。如果接受，論文和程式都要明講，避免把它包裝成完整 posterior inference。

**模型上真正需要先釐清的地方**
- \(M\) 的 closed-form 更新是用在哪個量上。最自然的是用條件標準化殘差
  \[
  r_t = D_t^{-1}(Y_t - X_t\beta - \lambda D_t|z_t|)
  \]
  去套 theorem，而不是直接對 \(Y_t\) 套。這個要在數學上說清楚。
- Tzeng-Huang 的 theorem 需要 replicate \(t=1,\dots,T\) 在共同 covariance 下獨立同分布。你這裡要確認的是：在給定 \((\beta,\lambda,z,\tau)\) 後，\(r_t\) 是否合理地可視為 conditionally iid。若你後面還想加時間依賴，theorem 就不能直接照搬。
- 你現在打算把 \(\widehat G = F\widehat M F' + \widehat{\sigma}_\xi^2 I\) 再標準化成 correlation matrix \(R\)。這步很重要，因為不然 \(M\) 會和 Morris 裡的 \(\sigma_t(s)\) 打架。但這也表示 theorem 最佳化的是 covariance \(G\)，真正進 likelihood 的卻是標準化後的 \(R\)。這是合理近似，但要知道它不是完全一致的 ML step。
- \(\sigma_\xi^2\) 和 \(D_t\) 的角色要明確分工。我的建議仍然是：\(D_t\) 管 marginal scale，\(\sigma_\xi^2\) 只作為 basis layer 裡的 nugget / regularization，再透過 correlation normalization 消化掉尺度問題。
- 要先決定 \(F\) 是完全固定的，還是會跟資料自適應更新。實作第一版時，我強烈建議把 MRTS basis 當固定設計，不要把 basis construction 也塞進 MCMC。

**計算上最容易踩雷的地方**
- 即使用 theorem 避開了 \(n\times n\) inverse，還是要注意數值穩定性。特別是 \(F'F\) 可能病態，所以 \((F'F)^{-1/2}\) 最好用 eigen 或 SVD 做，必要時加小的 ridge。
- \(\widehat{\sigma}_\xi^2\) 可能被估到 0，這時 Woodbury 和 determinant 計算會變得不穩。實作上通常要設一個 floor，例如 \(10^{-6}\)。
- 若 \(K\) 太接近甚至大於 \(T\)，basis-space sample covariance 的有效 rank 不夠，theorem 仍可算，但會很 noisy。第一版我會把 \(K\) 控制在明顯小於 \(T\) 的範圍。
- censored / thresholded data 的 imputation 會把 \(r_t\) 的估計帶進額外 Monte Carlo noise。這不是錯，但會影響 \(\widehat M\) 的穩定度。你可能需要考慮不是每次 iteration 都更新 \(M\)，而是每隔幾步更新一次。
- 預測公式要先想好。好消息是 MRTS 版其實比較容易做 out-of-sample prediction，因為新位置 \(s^*\) 只要能算 basis \(f(s^*)\) 就行，不必再組整個 Matérn cross-covariance。

**理論與論文層面要先補的說法**
- 要明講這是「hybrid Bayesian-profile method」，不是 full Bayes。
- 要說明 theorem 的使用條件是施加在條件殘差上，而不是原始觀測資料上。
- 要說明將 covariance \(G\) 標準化成 correlation \(R\) 的理由：保留 Morris 原始模型中 scale 與 dependence 的分工。
- 要交代 \(\widehat M\) 的不確定性沒有被完整傳播。若你希望稍微補回這一點，可以像我們前面說的，只加一個 scalar \(c\)，令 \(M=c\widehat M\)。

**驗證上一定要先規劃的東西**
- 先做 simulation，不要一上來就碰真資料。最少要比較三件事：原始 Morris-Matérn、你的 MRTS plug-in 版、以及一個更簡單的 diagonal-\(M\) 或 fixed-\(R\) baseline。
- 不只看 runtime，也要看 predictive calibration。像 coverage、CRPS、tail quantile、極端事件 exceedance probability 都要看。
- 要看 recovery of dependence structure。就算 marginal prediction 看起來差不多，空間 dependence 若歪掉，極端 joint behavior 會先出問題。
- 要追蹤 \(\widehat M\)、\(\widehat{\sigma}_\xi^2\)、以及標準化後 \(R\) 的穩定度，不然很可能表面上 MCMC 有在跑，實際上 covariance block 在震盪。

**我會建議的實作順序**
1. 先做不含 censoring 的 Gaussian 簡化版，確認 theorem update、Woodbury、prediction 都正確。
2. 再接回 Morris 的 \(z_t\)、\(\tau_t\)、\(\lambda\) 結構，但先不做 time dependence。
3. 最後才把 threshold imputation 和完整 skew-\(t\) sampler 接回來。

*看了以上報告，確立建模方向： 1. 決定 $F$ 是完全固定的。 2. 這裡不考慮 covariance 隨時間變動。所以確定 replicate $t=1,…,T$ 在共同 covariance 下獨立同分布。 我的想法，但不一定正確： 3. 在 replicate $t=1,…,T$ 在共同 covariance 下獨立同分布的情況下，不應該出現的問題： $K$ 太接近甚至大於 $T$ ，basis-space sample covariance 的有效 rank 不夠，theorem 仍可算，但會很 noisy。*

第 1、2 點我同意，這兩點其實把路線定得很清楚了：

- `F` 固定，代表我們不把 basis construction 的不確定性塞進推論。
- covariance 不隨時間變，代表 \(t=1,\dots,T\) 的 replicate 可以共同提供同一個空間 dependence block 的資訊。

但第 3 點，我會溫和地修正一下：**這個問題還是會存在**，不會因為 replicate 在共同 covariance 下 iid 就消失。

關鍵原因很簡單。你在 theorem 裡真正拿來估 \(M\) 的，是投影後的 \(K\)-維向量的 sample covariance。令

\[
\tilde r_t = (F'F)^{-1/2}F'r_t \in \mathbb{R}^K,
\]

那麼 theorem 裡的核心矩陣就是

\[
H
=
(F'F)^{-1/2}F'SF(F'F)^{-1/2}
=
\frac1T\sum_{t=1}^T \tilde r_t \tilde r_t'.
\]

這個矩陣的 rank 最多只有

\[
\operatorname{rank}(H) \le \min(K,T),
\]

如果另外還做了 sample centering，通常會變成 \(\min(K,T-1)\)。

所以：

- 即使 \(r_t\) 真的是 iid，資訊量的來源仍然只有 `T` 個獨立 replicate。
- 若 \(K > T\)，你想估的是一個 \(K\)-維空間裡的 covariance 結構，但資料最多只告訴你其中 `T` 個 directions。
- 結果不是 theorem 不能算，而是它只能穩定識別前面少數幾個 eigen-directions，其餘方向會自然被壓成 0 或非常不穩。

換句話說，**iid 幫助的是「這個 sample covariance 是合法的」**，但**不能突破「樣本數只有 \(T\)」的維度限制**。

更精確地講，你這裡會遇到的不是「不應該出現的問題」，而是：

1. `可識別 rank` 受限於 `T`。  
   所以當 \(K\) 接近或超過 \(T\) 時，\(\widehat M\) 的有效 rank 本來就不可能大於 \(T\)。

2. `高維低樣本` 造成 eigenvalue/eigenvector 很 noisy。  
   即使 theorem 有 closed form，closed form 不代表 statistical stability。

3. `在你的模型裡情況通常更嚴格`。  
   因為 \(r_t\) 不是直接觀測到的，而是依賴當前的 \(\beta,\lambda,z,\tau\) 算出來的條件殘差，所以有效資訊其實比理想 theorem 情境更少一點。

我會把這件事整理成一句實作原則：

\[
K \text{ should be chosen by } T \text{ as well as by } n.
\]

不是只看 \(K \ll n\)，還要看 \(K\) 相對於 \(T\) 是否太大。

我會建議的保守做法是：

- 理論上：避免 \(K > T\)。
- 實作上：最好讓 \(K\) 明顯小於 \(T\)，例如先從 \(K \le T/3\) 或 \(K \le T/2\) 的範圍開始測。
- 如果真的想放比較大的 \(K\)，就要接受 `effective rank` 仍然由 theorem 的 truncation 自動決定，本質上還是在做降維。

所以目前你的方向我會改寫成：

1. \(F\) 固定。  
2. replicate \(t=1,\dots,T\) 在共同 covariance 下 iid。  
3. 即便如此，\(K\) 仍不能太接近或超過 \(T\)，因為 \(M\) 的可識別有效 rank 受限於 sample size \(T\)，theorem 雖可計算，但估計會不穩且自動退化為低 rank。

沿這條線查下來，結論可以講得更精確。

EPA 的 `downscaler` metadata 確實支持你現在的判斷：它把 `CMAQ` 當成 **areal grid-cell output**，把監測值當成 **point-level air monitoring data**，而且 model fitting 只用 **paired CMAQ + monitor** 的位置；沒有監測站的 CMAQ cells 不進 fitting，整張 CMAQ surface 是在 prediction 階段才用。  
Sources:

- EPA metadata PDF: https://www.epa.gov/sites/default/files/2016-07/documents/data_fusion_meta_file_july_2016.pdf
- 舊版同系 metadata: https://www.epa.gov/sites/default/files/2015-09/documents/dsmetadataair_0612_0.pdf
- RSIG 說明頁: https://www.epa.gov/hesc/rsig-related-downloadable-data-files

但這裡有一個很重要的細節：**EPA downscaler 不是永遠固定同一種 pairing 演算法。**  
EPA 在 **2020-04-21** 的 downscaler 說明頁寫得更細，當時公開的 DS 版本是先對整張 CMAQ surface 做 spatially/temporally varying smoothing，再用平滑後的 derived regressor 去回歸監測值，也就是會借用鄰近 grid cells 的資訊，不是單純只拿同一格。  
Source:
- EPA snapshot page: https://19january2021snapshot.epa.gov/air-research/downscaler-model-predicting-daily-air-pollution_.html

所以更準確地說：

- **EPA metadata 那句話能證明的是**：fitting support 放在有監測站的 paired CMAQ-monitor data 上。
- **但它單獨不能證明**：所有 EPA DS 版本都一定是「原封不動取監測站所在那一格 CMAQ 值」；後期版本至少有一部分是平滑型的。

回到你這個 repo，判斷反而更清楚。這個 repo **不是在重現 EPA 完整 downscaler**，而是吃進一個**已經配好站點的 site-level CMAQ covariate**，再去 fit 自己的 ozone model。證據很直接：

- [us-all-setup.R](</D:/Github/spatial-skew-t/code/analysis/ozone/US-all/us-all-setup.R:19>) 用 `s[,1], s[,2]` 去取 CMAQ grid 的 `x,y`，表示 `s` 存的是 grid `col,row`。
- [us-all-setup.R](</D:/Github/spatial-skew-t/code/analysis/ozone/US-all/us-all-setup.R:68>) 直接做 `cmaq <- CMAQ[index, ]`。
- [us-all-setup.R](</D:/Github/spatial-skew-t/code/analysis/ozone/US-all/us-all-setup.R:514>) 註解直接寫 `CMAQ measurements at the AQS sites`。
- 我這輪也重新驗證過：`index = (row - 1) * nx + col` 完全成立，表示 `ozone_data.RData` 裡的 `s` 本質上就是一張 **site-to-cell lookup table**。

如果把 web 和 repo 合起來看，我會下這個結論：

**EPA downscaler metadata 支持「先把 CMAQ 與監測站做 paired support，再做 calibration/fusion」這個大方向；但你這個 repo 實際保存下來的資料結構，更像是較早期、較簡單的單一 grid-cell pairing 結果，而不是 EPA 後期那種平滑版 DS 演算法本身。**
